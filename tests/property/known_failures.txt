# Known property violations, one entry per line.

# An entry is `group/property [Alternative,Alternative]`. Anything matched here is
# still reported by a run, but does not fail it; anything unmatched fails the run.
# So this file is the line between "already understood" and "new", and the exit
# code tracks only the latter.
#
# WHAT THESE ARE: not hundreds of independent bugs. They are about a dozen root
# causes, each reached through many shape pairs -- one missing overload shows up
# once per pair that would have used it. tests/property/README.md triages them and
# gives a minimal witness for each; read that, not this.
#
# An entry ending in `[*]` accepts every pair of that property. That form is for a
# root cause whose reach is an accident of the draw: a fresh seed finds pairs an
# earlier one missed, and without the wildcard every new seed reports a handful of
# "new" signatures that are not new problems. The properties collapsed that way
# are listed below with the number of distinct pairs actually observed.
# Everything else is pinned to its exact pair, so a new pair there is reported and
# worth triaging.
#
# Regenerate from a single run with:
#     sh tests/property/run.sh --cases 20000 --update-baseline
# which writes exact pairs only -- the wildcards above are a maintainer's
# judgement and have to be reapplied by hand. This list is the union over seeds
